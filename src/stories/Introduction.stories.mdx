# Ash Shaw Makeup Portfolio - Component Library

Welcome to the **Ash Shaw Makeup Portfolio** component library! This Storybook documents all the reusable components, design tokens, and patterns used throughout the portfolio website.

## 🎨 About the Portfolio

The Ash Shaw Makeup Portfolio is a professional portfolio website showcasing festival artistry, UV makeup, and creative expression. Built with React, TypeScript, and Tailwind CSS, it features:

- **Professional Brand Identity** - Colorful paintbrush logo and vibrant gradient system
- **Comprehensive Portfolio** - 43+ portfolio entries with 19 Figma assets
- **Advanced Blog System** - Search, filtering, pagination, and rich content
- **Dark Mode Support** - Deep purple theme with smooth transitions
- **Full Accessibility** - WCAG 2.1 AA compliance throughout
- **CMS Integration** - Contentful headless CMS with fallback data
- **Email Integration** - SendGrid professional email system
- **Real Instagram Feed** - Instagram Graph API integration with caching

## 🎯 Design System

### Color Palette
The portfolio uses a vibrant gradient system:
- **Pink → Purple → Blue** - Primary CTA gradient
- **Blue → Teal → Green** - Secondary CTA gradient
- **Gold → Peach → Coral** - Accent gradient
- **Deep Purple** - Dark mode theme (#1e1b4b → #0f0b3a)

### Typography
- **Playfair Display** - Elegant serif headings
- **Inter** - Clean sans-serif body text
- **Righteous** - Bold display titles
- **Fluid Typography** - Responsive clamp() scales

### Spacing System
- **Fluid Spacing** - Responsive padding/margin (xs → 6xl)
- **Component-Specific** - Button, card, section spacing
- **Mobile-Optimized** - Touch-friendly tap targets (44px+)

## 🛠️ Development Guidelines

### Component Standards
All components follow strict guidelines:
- **TypeScript** - Full type safety with interfaces
- **Accessibility** - WCAG 2.1 AA compliance
- **Responsive** - Mobile-first design
- **Performance** - Optimized rendering

### Design Token Usage
Components use design token classes from `globals.css`:
```tsx
// Typography
<h1 className="text-hero-h1 font-title">Title</h1>

// Colors
<div className="bg-gradient-pink-purple-blue">Gradient</div>

// Spacing
<button className="px-button py-button">Button</button>
```

### Mock Data System
Components use centralized mock data from `/data/mock/`:
```typescript

```
